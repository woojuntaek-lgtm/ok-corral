# OK 목장 좌표

교류분석 ③ 「인생태도 — 나도 OK, 너도 OK」 [Psyche 13] 영상의 부록 앱입니다. 네 칸의 인생태도와 언스트(1971)의 OK 목장 행동(함께 가기·밀어내기·물러서기·주저앉기), 같은 사건에 대한 네 가지 반응 퀴즈, 아침·낮·저녁 내 자리를 찍어 보는 하루 좌표, 하루 한 번 좌표 점검, 요즘 마음의 기울기를 보는 간이 거울(8문항), 이고그램과 겹쳐 보기, 나와 남에게 건네는 OK 문장 만들기와 오늘의 정리를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 알림
- 내용은 정필 수심명의 영상 대본을 따랐습니다. 퀴즈 예문, 간이 거울 8문항과 계산, 문장 만들기 틀은 대본을 바탕으로 앱이 만든 것입니다.
- 간이 거울은 표준화된 OK그램 검사가 아니며, 성찰을 돕는 참고용입니다. 검사·진단이나 전문 상담을 대신하지 않습니다.
- 찍은 좌표, 고른 답, 적은 말은 저장하거나 보내지 않습니다.
